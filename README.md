### 📖 Overview

A full-featured electronics e-commerce web application built with **ASP.NET Core MVC**, featuring product browsing, cart management, user authentication, and an admin dashboard . designed with a clean, responsive Bootstrap 5 interface.
 

## ✨ Features

### 🛍️ Storefront
- Browse products with **search, brand/category filtering, and sorting** (newest, price low–high, high–low)
- Paginated product grid with responsive card layout
- Detailed product pages with quantity selector, related products, and trust badges
 

### 🔐 Authentication & Roles
- User registration & login via **ASP.NET Core Identity**
- Role-based access: **Admin**, **Client**, and guest views
- Admin dashboard for managing products, orders, and users
- Client dashboard for order history and profile management

### 🛒 Cart & Checkout
- Add/update/remove items with live cart badge updates
- Order confirmation flow with delivery address & payment method selection
- Toast notifications for cart actions

### 🎨 UI/UX
- Fully responsive design (mobile-first, Bootstrap 5 grid)
- Custom hero carousel, promotional banners, and category quick-links
- Modern card-based product and detail layouts
- Smooth scroll, back-to-top button, and polished micro-interactions

 

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Backend | ASP.NET Core MVC (C#) |
| ORM | Entity Framework Core |
| Database | SQL Server |
| Auth | ASP.NET Core Identity |
| Frontend | Razor Views, Bootstrap 5, Bootstrap Icons |
